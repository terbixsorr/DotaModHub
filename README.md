# 🎮 DotaMod Hub & Auto-Installer — Экосистема модов для Dota 2

Комплексный проект для запуска собственного сервиса кастомных скинов и VPK-модов для Dota 2 (в стиле **Dota2PornFxWeb**): веб-каталог + настольный менеджер автоматической установки в 1 клик.

## ⚡ Как запустить десктопное приложение (Auto-Installer):

Просто дважды кликни по **`Start-ModManager.bat`**:
1. Приложение откроется в стильном темном окне.
2. Оно **само определит путь к твоей установленной Dota 2** через реестр Steam.
3. Проверит статус `gameinfo.gi`.
4. Позволит в 1 клик установить любой выбранный мод.
5. Автоматически создаст резервную копию `gameinfo.gi.backup`.
6. По кнопке **«Удалить моды / Вернуть оригинал»** в любой момент вернет игру к заводскому состоянию без переустановки.

## 🌐 Как запустить веб-сайт:

1. Открой **`index.html`** в браузере (двойным кликом) — проверь дизайн и работу каталога.
2. Чтобы опубликовать в интернет: залей репозиторий на GitHub и включи **GitHub Pages** в настройках. Сайт станет доступен всему миру по бесплатному адресу.
