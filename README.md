## 📌 Архитектурные принципы и ключевые возможности

DotaMod Hub спроектирован как высокопроизводительное, надёжное десктопное приложение для управления локальными модификациями Dota 2. Архитектура исключает рассинхронизацию интерфейса и файловой системы:

### 1. Единый источник истины (`SkinCatalog`)
- **Zero-Desync Architecture**: Каталог, карточки, поиск, категории, избранное, окно детального просмотра и лайтбокс обращаются к строго типизированному объекту `SkinCatalog`.
- **Гарантированная целостность**: Исключены устаревшие раздельные массивы имён и картинок по индексам. Каждому скину принадлежит уникальный ID, проверенное локальное превью, категория, редкость и ссылка на файл.
- **Интеллектуальная система алиасов (`CATALOG_ALIASES`)**: При удалении дубликатов или обновлении структуры каталога сохранённые пользователем моды в «Избранном» автоматически связываются с каноническим объектом.

### 2. Отказоустойчивое файловое ядро (EBUSY Resilience)
- **Безопасная замена файлов на лету**: В операционной системе Windows файлы VPK могут временно блокироваться индексатором поиска, антивирусом или игрой. Функция `safeReplaceFile` использует циклы повторных попыток (backoff retry) и побитовое перезаписывание `copyFileSync` без преждевременного `unlink`.
- **Динамическое выделение архивов (`pakXX`)**: Если конкретный VPK-файл удерживается запущенным процессом, установщик автоматически выделяет следующий свободный номер (`pak100` и далее), не прерывая установку ошибкой.

### 3. Санитайзер VPK архивов (Engine Shader Guard)
- **Защита системных шейдеров Valve**: Парсер бинарного дерева VPK автоматически анализирует и отсекает системные пути движка (`materials/default`, `materials/engine`), предотвращая появление критических артефактов (красные текстуры Error, битые шейдеры героев, невидимые модельки).

### 4. Неинвазивная VAC-совместимая интеграция
- **Без инъекций в память (Zero Injection)**: Приложение не внедряет DLL, не перехватывает системные вызовы и не считывает память процесса `dota2.exe`.
- **Нативное монтирование**: Модификации размещаются исключительно в выделенном оверлейном каталоге клиента (`game/dota_russian`), а оригинальный файл конфигурации `game/dota/gameinfo.gi` остаётся полностью неизменным.

### 5. Оффлайн-first и локальный кэш
- **100% автономность**: Все 1 886 превью-изображений формата WebP и иконки героев хранятся локально в директории `assets/previews/`. Интерфейс загружается мгновенно без сетевых задержек.

## 🛠 Технологический стек

- **Core**: Node.js, Electron 28, Native Windows FileSystem APIs
- **Interface**: HTML5, Tailwind CSS, Glassmorphism UI (Dark Obsidian palette `#080b11`), FontAwesome Pro
- **Parsing & Binary Engine**: Встроенный парсер заголовков Source 2 VPK (Magic `0x55aa1234`), алгоритмы распаковки ZIP/TAR, WebM stream extractor

## 🚀 Установка и запуск

### Вариант 1. Скомпилированная версия
1. Запустите исполняемый файл приложения `DotaModHub.exe` (или ярлык на рабочем столе).
2. При первом запуске укажите путь к корневой папке игры (обычно `C:\Program Files (x86)\Steam\steamapps\common\dota 2 beta`).
3. Выберите желаемый скин или эффект в каталоге и нажмите **«Скачать»** / **«Установить»**.

### Вариант 2. Запуск из исходного кода
```bash
# Клонирование репозитория
git clone https://github.com/terbixsorr/DotaModHub.git
cd DotaModHub

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка дистрибутива
npm run build
```

## 🔒 Безопасность и VAC Compliance

```
[Dota 2 Client Engine]
         │
         ├── game/dota (100% оригинальные системные файлы Valve, gameinfo.gi чист) ──> [VAC Verification PASS]
         │
         └── game/dota_russian (Оверлей ресурсов pakXX_dir.vpk) ───────────────────> [Локальный рендер модов]
```

1. **Не затрагивает защищённую директорию `game/dota`**: Все системные файлы игры сохраняют оригинальные контрольные суммы Valve.
2. **Абсолютная изоляция процесса**: Приложение работает вне адресного пространства игры и не использует инжекты или системные хуки.
3. **Функция восстановления («Очистка VAC»)**: В настройках приложения доступно мгновенное восстановление абсолютно чистого состояния клиента Dota 2 в один клик.
